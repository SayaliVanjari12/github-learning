# Git Basics

## What is Git?

Git is a version control system that tracks changes in a project. It lets developers save versions of their work and go back to earlier versions when needed.

## What is GitHub?

GitHub is a platform where Git repositories can be hosted remotely. It allows developers to share code and collaborate with others.

## Git vs GitHub

Git is the tool that manages version history locally. GitHub is a service that can host Git repositories remotely and provides collaboration features such as pull requests.

## What is a repository?

A repository is a project managed by Git. It contains the project files along with Git's history of changes and commits.
